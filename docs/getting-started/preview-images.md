## Preview Images

!!! warning

     Preview images are experimental and can be highly unstable. Only download preview images if you know what you are doing and are comfortable recovering an unstable system.

Alongside the more stable Beta images, Armada OS offers Preview images which lie at the bleeding-edge of development. The preview update channel receives a new build with every commit made to the GitHub repository, which may offer more features or device support.

The latest five preview images can be found **[here](https://downloads.armadaos.dev/preview).**

Once your desired image has been downloaded, you may follow the steps in **[Flashing to an SD Card](./flashing-to-an-sd-card.md)** to install the image to SD as you would with the Beta images.

!!! note

     If you are currently running Armada's Beta branch and would like to try the Preview branch without reflashing, you may change the OS Update Channel from Beta to Preview. This may require you to enable Developer Mode in Settings and tick the "Show Advanced Update Channels" option under Developer in Settings. Likewise, you may switch from Preview back to Beta in the same way.
